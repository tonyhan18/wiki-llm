# 금 vs 비트코인

## 비교 배경
달러 약세 사이클에서 두 자산 모두 강세를 보임. 헤지 자산으로서의 역할 비교.

## 비교

| 차원 | 금 | 비트코인 |
|------|-----|---------|
| **역사** | 수천 년 | 2009년~ |
| **변동성** | 낮음 | 매우 높음 |
| **달러 헤지** | ✅ 강함 | ✅ 강함 |
| **안전자산** | ✅ 전통적 안전자산 | ⚠️ 논쟁적 (디지털 금) |
| **규제 리스크** | 낮음 | 높음 |
| **접근성** | 낮음 (물리/ETF) | 높음 (거래소) |
| **달러 약세 강세** | ✅ 확인됨 | ✅ 확인됨 |
| **포트폴리오 역할** | 방어 | 공격+방어 |

## 종합
- **달러 약세기** 두 자산 모두 강세 → [[달러-헤지]] 전략에서 함께 고려
- 금: 안정적 헤지, 변동성 낮음 → **코어 헤지**
- 비트코인: 공격적 헤지, 변동성 높음 → **위성 헤지**
- 손해를 보더라도 자산 배분 측면에서 **금 일부 보유 필수**
