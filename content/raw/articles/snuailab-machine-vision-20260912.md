# 스누아이랩 AI 머신비전 플랫폼 SMVT: 제조 현장 품질검사 자동화

**소스:** 한국경제 (https://www.hankyung.com/article/202609120151i)
**수집일:** 2026-09-12

## 요약
서울대 AI 교수진과 삼성 연구소 출신 연구원들이 참여해 설립한 피지컬AI 머신비전 전문기업 스누아이랩이 CAD 데이터를 활용해 제조 현장의 품질검사를 자동화하는 AI 머신비전 플랫폼 SMVT를 선보임.

## 핵심 포인트
- SMVT (SNUAILAB Machine Vision Tool): CAD 데이터를 AI가 분석해 검사 위치와 판정 기준 자동 설정
- 2D 표면 검사 + 3D 치수 검사를 하나의 환경에서 수행 (2D·3D 융합검사)
- 가상 결함 데이터 생성 기능
- 자연어로 검사 과정 구성 — 제조현장 AX(Adaptive Experience) 공략
- 스누아이랩: 2019년 설립, 서울대 현직 교수진 + 삼성 연구소 출신 합류
- 사명: SNU + AI + LAB
- 본사: 서울대 관악캠퍼스 자동화시스템공동연구소
- 딥러닝 기반 컴퓨터 비전 기술 주력 — 전기차·자동차·제조·인프라 분야 솔루션 공급
- 기존 비전AI 플랫폼 'AutoCare'에 이은 새 플랫폼
