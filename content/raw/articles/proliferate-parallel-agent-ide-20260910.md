# Proliferate - 여러 코딩 에이전트를 병렬로 실행하는 오픈소스 AI IDE

## 요약
- Claude Code, Codex, OpenCode, Cursor, Grok에 서로 다른 작업을 맡기고 진행 상황과 코드 변경을 한곳에서 확인하는 데스크톱 IDE
- 작업마다 별도의 Git 브랜치와 작업 디렉터리(worktree)를 만들어 에이전트들이 서로의 파일을 덮어쓰지 않고 동시에 작업
- 오픈소스 AI IDE로, 다중 에이전트 오케스트레이션을 개발자 워크플로에 통합
