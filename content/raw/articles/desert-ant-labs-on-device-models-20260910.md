## 핵심 요점

- 유럽 AI 연구소 Desert Ant Labs가 클라우드 없이 기기에서 실행되는 소형 특화 모델 18개 공개
- 안정 버전 12개, 베타 6개 — 오디오·비전·텍스트 작업별 하나의 모델
- Swift·Kotlin·JavaScript용 SDK 제공 → 모바일·웹·임베디드 환경 즉시 적용 가능
- 작업당 하나의 특화 모델을 기기에서 실행 → 호출당 비용과 서버 왕복 제거
- 클라우드 의존 없는 프라이버시 보장, 오프라인 작동, 지연 시간 최소화

- 에지 AI(edge AI) 모델이 상용 SDK 수준으로 성숙
- 다목적 대형 모델(GPT 등)과 단일 작업 특화 소형 모델의 이원화 가속
