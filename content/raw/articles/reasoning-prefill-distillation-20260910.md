# Qwen 3.8, GPT-5.5 Pro의 추론 프리필을 따름

## 요약
- GPT-5.5 Pro 추론의 첫 1%를 추론 채널에 미리 넣자, Qwen3.8 A95B의 답변과 GPT-5.5 Pro 답변 간 중복 점수가 16.79%에서 34.97%로 상승
- STEM·비STEM·합성 퍼즐 각 15개, 총 45개 문제에서 일반 응답과 추론 프리필 응답을 비교
- 대상 모델의 추론 품질이 높을수록 프리필 효과가 큼
- 강력한 모델의 추론 패턴 일부를 경량 모델에 주입하여 응답 정렬을 유도하는 기법

## 핵심 개념
- **추론 프리필(reasoning prefill):** 강력한 모델이 생성한 추론 토큰 시퀀스의 앞부분(1%)을 대상 모델의 추론 채널에 사전 입력
- **추론 증류(reasoning distillation):** 추론 과정 자체를 전달하여 경량 모델의 사고 패턴을 강제 정렬
- 중복 점수(overlap score) 2배 이상 상승 = 응답 스타일·내용 정렬 효과 확인

## 시사점
- 추론 모델 간 지식 전달의 새로운 형태: 파인튜닝 없이 추론 프리필만으로 정렬 가능
- 비용 효율적: GPT-5.5 Pro 전체 추론을 복제할 필요 없이 1%만 주입
- [[gpt-6-astra|GPT-6 Astra]]의 하네스(인프라) 격차와 맞물림 — 모델 능력뿐 아니라 추론 컨텍스트 관리가 성능을 결정
