# Quiz Gate: git diff 기반 코드 리뷰 퀴즈 앱

## 요약
AWS에서 발표한 AI가 팀 생산성에 미치는 영향 영상에서, AI가 작성한 코드의 컨텍스트를 확실히 알고 있는 팀이 더 생산성이 높다는 점에 착안해 만든 GitHub 앱. PR을 만들면 git diff 기반으로 코드 변경점에 대한 문제를 풀어볼 수 있어, 머지 전에 코드를 확실히 이해하도록 돕는다.

## 핵심 내용
- AI 작성 코드의 컨텍스트 이해가 팀 생산성의 핵심
- git diff 기반 퀴즈로 코드 리뷰 품질 향상
- 머지 전 코드 변경점 검증 → AI 코딩 시대의 품질 관리 도구
- 개발자가 AI 코드를 수동 검증하는 프로세스의 자동화
