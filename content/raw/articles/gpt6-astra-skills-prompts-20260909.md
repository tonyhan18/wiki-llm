# GPT-6 Astra를 위한 스킬과 프롬프트 다시 생각하기

## 요약
코딩 에이전트의 성능 향상으로 과거에 필요했던 세세한 유도와 보조 절차의 필요성이 줄어들었다. GPT-6 Astra에서는 누적된 Skills/AGENTS.md/작업 프롬프트를 재검토하는 일이 더욱 중요해졌다. 스킬 설명은 짧고 사용 조건이 명확해야 하며, 여러 작업 흐름을 다루는 복잡한 스킬은 분리해야 한다.

## 핵심 내용
- 에이전트 능력 향상으로 기존 프롬프트 엔지니어링의 과잉 영역 축소
- 스킬 설명: 짧고, 사용 조건 명확, 단일 목적
- 복잡한 워크플로우는 분리된 단일 스킬로 관리
- AGENTS.md 재설계: 과도한 가이드보다 최소한의 명확한 지시
- 모델 능력이 향상될수록 인간 개입 지점이 "지시"에서 "검토"로 이동
