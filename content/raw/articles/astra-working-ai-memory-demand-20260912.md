# 삼전닉스 행복한 비명: '일하는 AI' 아스트라와 메모리 수요

**소스:** 한국경제 (https://www.hankyung.com/article/202609118801g)
**수집일:** 2026-09-12

## 요약
오픈AI의 새 모델 GPT-6 아스트라(Astra)가 폭발적 관심. '대답하는 AI'에서 '일하는 AI'로 전환. AI가 맡는 일이 늘어날수록 컴퓨팅 자원과 메모리 역할이 커짐.

## 핵심 포인트
- GPT-6 Astra: 컴퓨터·브라우저 직접 사용, 자료 조사·코드 작성·다단계 업무 수행
- 개발자용 모델: 최대 105만 토큰 컨텍스트 윈도우
- 음성 요청으로 여러 작업을 병렬 처리 — 심대열 오픈AI 코리아 코덱스 엔지니어 시연
- 젠슨 황: "AGI가 도래했다" 선언 / 그레그 브록먼: "AGI 시대에 오신 것을 환영한다"
- 아스트라 = 초기 AGI 단계 진입 변곡점 (김동원 KB증권 리서치본부장)
- AI 모델 경쟁 격화 → 메모리(HBM) 수요 구조적 증가 → 삼성전자·SK하이닉스 수혜
- 삼성전자: HBM4 공급 확대, HBM4E 샘플 제공
- SK하이닉스: HBM4 양산 출하, HBM4E 샘플 공급
- 2분기 D램 점유율: 삼성 39.4% + SK하이닉스 24.9% = 64.3%
- 오픈AI 코리아 김경훈 총괄대표: "AI 반도체 수요 지속, 한국 반도체 공급망 협력 강조"
- 에이전틱 AI 확산 → 서버 D램 + HBM 수요 증가, 일반 메모리 수요 기반까지 확대
