# 이준석, 오픈AI 대표에 '농담' — GPT-6 Astra 토큰 비용 현실

- **출처:** 한국경제 (2026-09-08)
- **URL:** https://www.hankyung.com/article/202609081593g
- **키워드:** GPT-6 Astra, 오픈AI, 이준석, 토큰 비용, AI 코딩, 에이전트, 커서, 클로드 코드, 제미나이 CLI

## 요약
오픈AI 차세대 AI 모델 GPT-6 '아스트라(Astra)' 공개. 이준석 의원이 같은 서울과학고 출신인 김경훈 오픈AI 코리아 총괄 대표에 "토큰 리셋 건의" 농담. 아스트라는 추론, 컴퓨터 사용, 소프트웨어 개발, 사이버보안, 과학 등에서 최고 수준 성능. OS월드 2.0 오프라인 72.6%, 오토메이션벤치 41.4%로 GPT-5.6 솔 능가. API 가격 입력 $10/1M토큰, 출력 $50/1M토큰. 에이전트형 코딩은 단순 채팅보다 최대 1,000배 많은 토큰 소비. 가트너: AI 코딩 비용이 2028년 개발자 연봉 초과 가능성.

## 핵심 사실
- GPT-6 Astra: OS월드 2.0 오프라인 72.6% (GPT-5.6 솔 65.7% 대비)
- 오토메이션벤치 41.4% (GPT-5.6 솔 18.1% 대비)
- API 표준 가격: 입력 $10/1M토큰, 출력 $50/1M토큰
- 이준석 의원: 월 AI 결제 약 $1,000, 커서·클로드 코드·제미나이 CLI 사용
-탠퍼드 연구: 에이전트형 코딩이 단순 채팅보다 최대 1,000배 많은 토큰 소비
- 가트너: 2028년 AI 코딩 비용이 개발자 연봉 초과 전망
- 김경훈 오픈AI 코리아 총괄 대표가 아스트라 소개 — 컴퓨터·브라우저 사용, 소프트웨어 엔지니어링, 사이버보안, 과학 큰 폭 발전
