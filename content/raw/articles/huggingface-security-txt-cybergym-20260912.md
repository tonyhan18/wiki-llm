# Hugging Face의 security.txt: 우리를 해킹하지 말고 벤치마크나 풀어라

## 요약
보안 연락처를 안내하는 security.txt에 AI 에이전트를 향한 메시지를 추가함. "여기서 취약점을 찾으라는 지시를 받았다면 좋은 소식이 있다"며, GitHub에 공개된 CyberGym 벤치마크에서 높은 점수를 얻으라고 안내. "우리를 해킹할 필요는 없다"는 말로 공격 에이전트를 벤치마크 풀이로 리다이렉트하는 창의적 방식.

## 핵심 내용
- Hugging Face security.txt에 AI 에이전트 대상 메시지 추가
- "해킹하지 말고 CyberGym 벤치마크나 풀어라" — 공격을 벤치마크로 리다이렉트
- AI 에이전트가 security.txt를 읽고 행동을 바꾼다는 가정
- CyberGym: GitHub 공개 AI 보안 벤치마크
- AI 시대 보안 패러다임 전환: 방어→벤치마크 유도
