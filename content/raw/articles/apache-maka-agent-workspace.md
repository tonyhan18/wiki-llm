# Apache Maka — 로컬 우선 AI 에이전트 워크스페이스

## 요약
원하는 AI 모델을 연결해 데스크톱이나 터미널에서 작업을 맡기고, 에이전트가 무엇을 했는지 실행 과정까지 확인할 수 있는 작업 공간.

대화뿐 아니라 도구 호출과 결과, 권한 승인 여부, 종료 상태를 순서대로 기록하며, 이 기록을 화면 표시와 다음 요청 구성, 비정상 종료 후 복구에 활용한다.

### 핵심 특징
- **로컬 우선(local-first):** 데스크톱/터미미널에서 직접 실행
- **실행 기록(agent log):** 도구 호출, 권한 승인, 종료 상태를 순차 기록
- **복구 지원:** 비정상 종료 후 기록 기반 복구
- **모델 유연성:** 원하는 AI 모델을 연결 가능
