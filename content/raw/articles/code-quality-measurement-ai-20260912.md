# 코딩이 해결됐다면, 코드의 조잃함은 어떻게 측정할까?

## 요약
AI가 테스트를 통과하는 코드를 만들어도 불필요한 추상화와 중복, 나쁜 설계까지 피하는 것은 아니며, 기능을 추가할 때마다 코드가 불어나면 사람도 에이전트도 관리하기 어려워짐. 기능이 제대로 동작하는지는 테스트로 확인할 수 있지만, 코드가 얼마나 조잃한지는 측정하기 어렵다는 근본 문제 제기.

## 핵심 내용
- 테스트 통과 ≠ 좋은 코드 (불필요한 추상화, 중복, 나쁜 설계 남아있음)
- 코드가 불어나면 사람도 AI 에이전트도 관리 불가
- 기능 정상 작동은 테스트로 검증 가능, 코드 품질(조잃함)은 측정 불가
- AI 코딩 시대의 새로운 병목: 품질 측정 메트릭 부재
- 코드 복잡도·유지보수성 측정의 근본적 난제
