# LLM 인지 영향

## 개념
LLM이 단순 도구가 아니라 인간의 사고방식, 글쓰기, 신뢰 체계에 구조적 영향을 미치는 현상. 전염병 동역학 모델로 확산을 설명하고, 글쓰기 신뢰 훼손과 독자-작가 계약의 무너짐을 지적.

## 핵심 인사이트

### 인지 바이러스로서의 LLM
- 개인의 점진적 도입도 사회적 강화와 결합하면 집단 수준의 지속적 의존으로 급격히 전환될 수 있음
- 사용자 상태를 비결합 → 결합(자율성 유지) → 지속적 의존의 3단계로 분류
- 도입 압력과 독립적 사고의 가치가 임계점을 넘으면 사회적 전환 발생
- LLM이 사회적 인프라로 전환될 때 인지 자율성 상실 위험

### 글쓰기 신뢰 훼손
- LLM이 대신 쓴 글은 이모지, 한 문장 문단, 반복적 대조 구문, 긴 대시 등으로 식별 가능
- LinkedIn에서 LLM 글 사용 시 글쓴이 고유의 목소리가 사라지고 독자가 진정성 의심
- 단기적 효율은 얻지만 장기적 신뢰 자산 훼손

### 독자-작가 신뢰 계약
- 글쓰기는 생각을 전달하면서 검증하고 정제하는 과정
- 글쓴이가 직접 만들지 않은 문장을 독자가 애써 이해해야 한다면 신뢰 계약 무너짐
- 독자의 시간과 노력에 대한 존중이 글쓰기의 근본 전제

## 미해결 질문
- LLM 사용을 줄이는 것이 유일한 대안인가, 아니면 사용 패턴을 설계할 수 있는가?
- 사회적 임계점을 넘기 전에 인지 자율성을 보호할 제도적 장치는 무엇인가?
