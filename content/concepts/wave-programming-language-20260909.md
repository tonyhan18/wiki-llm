# Wave 프로그래밍 언어

## 정의
Wave는 C와 Rust 등 저수준 언어에서 영감을 받아 개발 중인 프로그래밍 언어. LLVM을 백엔드로 사용해 네이티브 코드로 컴파일하며, 시스템 프로그래밍을 포함한 다양한 영역에서 사용 가능한 것을 목표로 함.

## 핵심 내용

### 설계 철학
- C의 간결함과 Rust의 안전성에서 영감
- LLVM 백엔드 → 네이티브 성능 + 최적화 인프라 활용
- 시스템 프로그래밍 영역 타겟 → 운영체제, 임베디드, 고성능 서버
- 프로젝트가 활발히 진화 중 — 작년 소개 이후 방향성 변경

### AI 시대의 새 언어 의미
- AI 코딩 보조 도구가 언어 학습 비용을 낮추면서 새 언어 진입 장벽 완화
- [[programming-as-art-20260909|프로그래밍은 예술이다]]: 언어 설계 자체가 창작 행위
- [[build-vs-buy-ai|Build vs Buy]]: 새 언어 선택은 장기 운영 책임과 연결 — 커뮤니티·생태계·유지보수가 핵심
- [[extreme-ssr-20260909|극단적 SSR]]: 경량화된 기술 스택에 대한 탐색과 맥락 — 복잡성 최소화 추구

### 시스템 프로그래밍 언어 경쟁 구도
- Rust의 안전성 vs C의 성숙도 vs Zig의 단순함 vs Wave의 신규 접근
- LLVM 기반 언어 생태계 확장 — 백엔드 표준화로 프론트엔드 다양성 증가
- AI 시대에 인프라/시스템 계층의 중요성 재부각

## 미해결 질문
- Wave가 Rust/C의 틈새를 어떤 차별점으로 채울 것인가?
- AI 코딩 도구가 새 언어 채택을 가속하는가, 아니면 기존 언어 의존을 강화하는가?
- 시스템 프로그래밍 언어 시장에 새 진입자가 생존할 수 있는가?
