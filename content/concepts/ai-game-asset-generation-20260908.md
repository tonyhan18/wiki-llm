# AI 게임 에셋 생성: stage-gen

## 개요
오픈소스 도구 stage-gen은 게임의 아트 디렉션과 참고 이미지를 바탕으로 캐릭터·배경·지형 등 2D 게임 에셋을 자동 생성한다. GPT 기반 생성 파이프라인에 입력 패키지(아트 디렉션, 참고 이미지 등)를 제공하면, 러너/플랫포머 데모에 즉시 투입 가능한 에셋이 산출된다.

## 핵심 사실
- **도구:** stage-gen (오픈소스)
- **입력:** 아트 디렉션 + 참고 이미지 → GPT 기반 파이프라인
- **출력:** 캐릭터·배경·지형 2D 에셋
- **검증:** 러너/플랫포머 데모에 에셋 적용 확인
- **의의:** AI 콘텐츠 생성이 게임 개발 파이프라인 전 단계로 확장

## 분석
### AI와 창작 파이프라인
- 아트 디렉션을 텍스트/참고 이미지로 정의 → AI가 에셋量产 → 게임 데모까지 자동화
- [[taste-and-ai|안목과 AI 시대]] — 아트 디렉션(안목)을 입력으로 제공하는 구조: AI가 실무를 대신하지만 방향성은 인간이 설정
- [[ai-org-transformation|AI 조직 전환]] — 게임 스튜디오 업무 프로세스 재구조화 사례

### 생산자 중심의 활용
- [[producer-focus|생산자의 몰입]] — 도구 활용이 아니라 파이프라인 자체를 설계하는 생산자 역할
- stage-gen은 "도구를 쓰는 것"이 아니라 "도구를 만드는 것"에 가까움

## 미해결 질문
- 생성된 에셋의 품질이 상용 게임 수준에 도달할 수 있는가?
- 아트 디렉션 입력 품질이 출력 품질을 얼마나 결정하는가?
