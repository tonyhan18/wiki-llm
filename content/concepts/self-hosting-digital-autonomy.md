# 셀프 호스팅과 디지털 자립

## 개념
자체 서버와 인프라를 운영하여 데이터 주권과 자율성을 확보하려는 실천과 그 의미. 클라우드 의존에서 벗어나 개인과 공동체가 디지털 인프라를 직접 통제하는 방향.

## 핵심 인사이트

### Cloud in a Bottle: 셀프 호스팅 대중화
- 컨테이너형 앱 + 통합 인증을 결합한 오픈소스 개인 클라우드
- 셀프 호스팅을 시스템 관리 부업이 아닌 스마트폰처럼 쉬운 경험으로 만드는 것이 목표
- 루트 권한 없는 보안 강화 컨테이너에서 앱 실행

### EU 기반 Git 호스팅: 데이터 주권
- Pushin.eu: Git 저장소, 이슈, CI를 EU 안에서 호스팅
- GDPR과 개인정보 보호를 운영 중심에 둠
- 사용자 코드로 AI 모델 학습 거부 — AI 기능보다 개발자 경험과 고가용성에 집중

### NAS 파일시스템: 데이터 보관의 기초
- ZFS: 데이터 무결성, 스냅샷, 암호화된 원격 증분 복제로 인기
- Btrfs, ext4+LVM, MergerFS 등 대안 존재
- 데이터 자산의 안전한 보관은 디지털 자립의 기초 인프라

### A/I 종료: 자립 인프라의 취약성
- Autistici/Inventati 25년 운영 종료, 이용자와 공동체 보호가 이유
- 정치적 압력에 의해 독립적 인프라가 종료되는 사례

### Nitter: 오픈소스 대체 프론트엔드의 지속
- X Corp.의 폐쇄 요구에도 법률 자문 후 서비스 재개
- 개인정보 보호와 성능에 초점을 둔 무료 오픈소스 Twitter 대체 프런트엔드

## 미해결 질문
- 셀프 호스팅의 진입 장벽을 낮추는 것이 자립을 넘어 책임(보안, 백업)으로 이어지는가?
- 독립적 인프라가 정치적/법적 압력에 어떻게 지속 가능한가?
