# KT 다크팩토리 플랫폼

## 개념
KT가 다임리서치와 사업화 협약을 맺고 무인공장 '다크팩토리' 플랫폼을 개발. 다크팩토리는 불을 끈 상태로 24시간 무인 가동하는 완전 자동화 공장으로, 로봇·AI 비전·IoT가 융합된 제조 혁신의 최종 형태.

## 핵심 인사이트

### 다크팩토리의 의미
- 인간 없이 24시간 가동 = 물리적 작업 비용의 구조적 붕괴
- [[robotics-gpt-moment-20260908|로봇 GPT 모멘트]]의 산업 적용 사례
- 로봇 비용 붕괴 → 무인 공장 경제성 확보 → 제조업 패러다임 전환

### KT의 역할
- 통신사 인프라(5G/IoT) + AI 플랫폼 = 다크팩토리 운영 인프라
- 다임리서치(제조 자동화 전문)와 협력
- 통신사가 제조업 AI 진출 → [[ai-sector-expansion-20260908|AI 도메인 확장]]의 또 다른 사례

### AI 확장 계층
1. **소프트웨어 AI:** 네이버 의료 AI, GPT-6 — 정보 처리
2. **국방 AI:** [[hanwha-aerospace|한화에어로스페이스]] GPU 팜 — 방산
3. **제조 AI:** 다크팩토리 — 물리적 생산 자동화
4. **인프라 AI:** [[sgc-ai-datacenter-20260908|AI 데이터센터]] — 전력/냉각

## 분석

### 물리적 작업 비용 붕괴
- [[robotics-gpt-moment-20260908|로봇 GPT 모멘트]]에서 예측한 비용 붕괴가 구체화
- 다크팩토리 = 인건비 0 → 노동 집약적 제조업의 패러다임 변화
- 한국 제조업의 인구 감소 대응책

### 투자 시사점
- 다크팩토리 플랫폼 = KT의 새로운 B2B 수익 모델
- 제조업 패러다임 전환 → 자동화 설비·로봇 기업 수혜
- [[semiconductor-industry|반도체 산업]]의 파운드리 무인화와 연결
