# 스누아이랩 SMVT: AI 머신비전으로 제조 품질검사 자동화

## 정의
서울대 AI 교수진과 삼성 연구소 출신 연구원이 설립한 피지컬AI 머신비전 전문기업 스누아이랩이 공개한 AI 머신비전 플랫폼 SMVT. CAD 데이터를 활용해 제조 현장 품질검사를 자동화.

## 핵심 내용
- **SMVT (SNUAILAB Machine Vision Tool)**: CAD 데이터를 AI가 분석해 검사 위치·판정 기준 자동 설정
- **2D·3D 융합검사**: 2D 표면 검사 + 3D 치수 검사를 하나의 환경에서 수행
- **가상 결함 데이터 생성**: 학습용 합성 결함 데이터 자동 생성
- **자연어 검사 구성**: 자연어로 검사 과정을 설정 — 제조현장 AX 공략
- **회사 배경**: 2019년 설립, 서울대 교수진 + 삼성 연구소 출신 합류
- 사명: SNU + AI + LAB, 본사 서울대 관악캠퍼스
- 기존 플랫폼 'AutoCare'에 이은 신규 플랫폼
- 전기차·자동차·제조·인프라 분야 솔루션 공급

## 의미
[[samsung-sds-robot-orchestration-20260908]]의 피지컬 AI 확장과 연결: 제조 현장 자동화가 로봇 오케스트레이션에서 머신비전으로 확장. [[ai-sector-expansion-20260908]]의 AI 도메인 확장(의료·국방·파운드리)에 머신비전 제조 검사 추가. [[semiconductor-industry]]의 파운드리 수요와 간접 연결: 머신비전 품질검사는 반도체·전기차 제조 품질 관리에 적용 가능. [[robotics-gpt-moment-20260908]]의 로봇 비용 붕괴와 결합: 머신비전은 로봇 자동화의 '눈' 역할, 로봇 확산의 전제 조건.

## 쟁점
- CAD 기반 자동 설정의 정확도: 실제 제품과 CAD 간 차이
- 자연어 검사 구성의 신뢰성: 비전문가 설정의 품질
- 기존 AutoCare와 SMVT의 포지셔닝 차이
