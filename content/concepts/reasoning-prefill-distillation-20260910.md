# 추론 프리필: 추론 패턴 전달을 통한 모델 정렬

## 개념
강력한 추론 모델(GPT-5.5 Pro)이 생성한 추론 토큰 시퀀스의 앞부분(1%)을 경량 모델(Qwen3.8 A95B)의 추론 채널에 사전 입력(prefill)하면, 경량 모델의 응답이 강력 모델과 유사해지는 현상. 중복 점수(overlap score)가 16.79%에서 34.97%로 2배 이상 상승.

## 핵심 사실

### 실험 설계
- **대상:** STEM 15문제, 비STEM 15문제, 합성 퍼즐 15문제 (총 45문제)
- **비교:** 일반 응답 vs 추론 프리필 응답
- **측정:** GPT-5.5 Pro 답변과 Qwen3.8 A95B 답변 간 중복 점수
- **결과:** 16.79% → 34.97% (추론 첫 1%만 주입)

### 작동 원리
- 추론 모델은 추론 채널(reasoning channel)에서 사고 과정을 생성한 후 최종 답변을 출력
- 강력 모델의 추론 시퀀스 앞부분을 주입하면, 경량 모델이 해당 추론 궤도를 따라가며 정렬된 결론에 도달
- 파인튜닝이나 가중치 변경 없이, **추론 컨텍스트만으로** 응답 품질 정렬 가능

## 분석

### 추론 증류의 새 형태
- 전통적 모델 증류(distillation)는 가중치·로짓(logit) 수준에서 지식 전달
- 추론 프리필은 **추론 궤도(reasoning trajectory)** 자체를 전달 — 더 높은 수준의 지식 표현 전송
- 비용 효율적: 전체 추론 복제 없이 1%만으로 2배 정렬 효과

### 하네스(인프라)와 추론 관리의 연결
- [[gpt-6-astra|GPT-6 Astra]]의 하네스 격차(54.8% vs 99.9%)와 동일한 맥락 — 모델 능력뿐 아니라 추론 컨텍스트 관리가 성능을 결정
- 추론 프리필은 하네스 수준의 제어: 추론 시작점을 외부에서 주입하여 모델 행동을 유도
- [[gpt6-astra-loop-transformer-20260910|루프형 트랜스포머]]의 해석 가능성 저하 문제와 연결 — 추론 과정이 짧아질수록 외부 주입으로 제어하는 기법의 가치 부각

### 모델 경쟁과 비용 구조
- [[gpt6-astra-token-economics-20260908|GPT-6 Astra 토큰 경제학]]의 연장선 — 강력 모델의 추론을 경량 모델에 전달하여 총비용 절감 가능성

## 미해결 질문

- 어떤 추론 단계(초기 분석 vs 중간 전개 vs 최종 결론)의 프리필이 가장 효과적인가?
