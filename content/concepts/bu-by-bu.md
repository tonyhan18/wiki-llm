# 부바부 (부서 바이 부서)

## 개념
같은 회사라도 **어떤 부서/어떤 선배를 만나느냐**에 따라 업무 내용과 삶의 질이 완전히 달라지는 현상.

## 삼성전자 사례

### 운이 크게 작용하는 직무 배치
- 입사 후 어떤 선배를 만나느냐 → 직무가 갈림
- 개발자 / 설비 엔지니어 / 시설 관리 / 서버 엔지니어
- **어떤 일을 하게 될지 운을 많이 탐**

### 의외의 좋은 직무
- **시설 정비:** 아침 체크리스트 점검 → 대기 → 점심 → 점검 → 퇴근
- 연봉 1억+
- 개발자보다 오히려 좋은 분야도 많음

### 워라밸과 행복
- 시설 직무 + 결혼 + 육아 → 워라밸 챙기며 행복한 삶 가능
- "평범한 커리어에 역설적임" — [[Top-Down-선택법]]과 연결

## 교훈
- 입사 전에 부서를 고를 수는 없지만, 인지하고 있어야 함
- 어떤 부서든 **정답은 있다**
- 개발자만이 정답이 아님 → 시야를 넓혀야 함
