# 해커톤에서 배운 것

## 핵심 교훈

### 1. 아이디어 공유는 정말 중요함
소통을 안 하면 안 됨. 팀원 간 아이디어가 공유되지 않으면 각자 다른 방향으로 일하게 됨.

### 2. 해커톤 참가 전 충분한 토론이 있어야 함
코딩 시작 전에 팀 전체가 같은 그림을 보고 있어야 함. 충분한 토론 없이 시작하면 중간에 방향이 갈림.

### 3. 기능을 만들려고 하면 안 됨
- 해커톤에서 **하나의 기능만 만들어도 대단한 거임**
- 빠르게 제작해서 빠르게 전달해야 하기 때문
- 욕심내서 여러 기능을 만들려고 하면 하나도 완성 못 함

### 4. AI에게 맡기지 마셈
- **내 머릿속에 없는 걸 AI에게 맡기지 마셈**
- AI와 함께 고민은 해 볼 수 있음
- 하지만 방향과 아이디어는 사람이 가져야 함

### 5. 팀 전체가 같은 생각으로 일해야 함
- 리더를 포함 팀원 전원이 **같은 생각**을 가지고 일해야 함
- 한 명이라도 다른 방향을 보면 결과물이 파편화됨
