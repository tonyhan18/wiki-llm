# GPT-6 Astra '일하는 AI' 전환과 삼전닉스 메모리 수혜

## 정의
오픈AI의 GPT-6 아스트라(Astra)가 '대답하는 AI'에서 '일하는 AI'로 전환하며, AI 에이전트의 업무 수행이 늘어남에 따라 HBM·메모리 수요가 구조적으로 증가하는 가운데 삼성전자와 SK하이닉스가 수혜를 받는 분석.

## 핵심 내용
- **GPT-6 Astra**: 컴퓨터·브라우저 직접 사용, 다단계 업무 수행, 105만 토큰 컨텍스트 윈도우
- **음성 기반 병렬 작업**: 심대열 오픈AI 코리아 코덱스 엔지니어 시연 — 음성 요청으로 여러 작업 동시 처리
- **AGI 선언**: 젠슨 황 "AGI 도래", 그레그 브록먼 "AGI 시대 환영"
- **아스트라 = 초기 AGI 변곡점** (김동원 KB증권)
- **메모리 수요 구조적 증가**: 모델 경쟁 격화 → HBM 수요 증가
- **삼성전자**: HBM4 공급 확대, HBM4E 샘플 제공
- **SK하이닉스**: HBM4 양산 출하, HBM4E 샘플 공급
- **2분기 D램 점유율**: 삼성 39.4% + SK하이닉스 24.9% = 64.3%
- **에이전틱 AI 확산**: 서버 D램 + HBM 수요, 일반 메모리 수요 기반까지 확대

## 투자 시사점
- AI 모델 경쟁 → 메모리 수요 구조적 증가 → 삼성·SK하이닉스 수혜 지속
- 에이전틱 AI 확산: HBM뿐 아니라 일반 서버 D램 수요까지 확대
- 한국 D램 점유율 64.3% — 글로벌 AI 기업의 한국 반도체 의존도
